# Vocabulário recomendado do PTS

Este vocabulário dá as palavras recomendadas do Português Técnico Simplificado (PTS).
Nós criamos esta lista. Ela não é uma tradução do dicionário do ASD-STE100.
Cada linha mostra uma palavra, a sua classe gramatical e as suas formas irregulares.

Formato: `PALAVRA (classe) [formas irregulares]`

Classes: v = verbo, s = substantivo, adj = adjetivo, adv = advérbio,
prep = preposição, pron = pronome, conj = conjunção, art = artigo, num = numeral.

Regras deste vocabulário:
- Use uma palavra somente com a classe gramatical que esta lista dá.
- O plural dos substantivos e dos adjetivos é permitido. O feminino dos adjetivos é permitido.
- Os verbos regulares são permitidos nas formas da regra 3.2. A ferramenta de verificação gera estas formas.
- Os verbos irregulares mostram as formas irregulares entre colchetes.
- Uma palavra que não está nesta lista é permitida somente como nome técnico ou verbo técnico. Consulte `substituicoes.md`.
- Algumas palavras têm um sentido restrito. Consulte a seção "Palavras com sentido restrito" no fim deste arquivo.

## Palavras com sentido restrito

Estas palavras têm um único sentido no PTS. Não use estas palavras com outro sentido.

| Palavra | Sentido no PTS | Não use com o sentido de |
|---|---|---|
| ACESSO (s) | permissão ou caminho para entrar | ataque, crise |
| CARREGAR (v) | colocar carga, energia ou dados em | levar algo pesado (use "levar") |
| CHAVE (s) | interruptor ou ferramenta | solução de um problema |
| COLOCAR (v) | pôr em uma posição | dizer uma opinião |
| CORRENTE (s) | corrente elétrica ou de fluido | corrente de metal (use o nome técnico) |
| DADO (s) | informação | peça de jogo |
| DEVER (v) | obrigação | probabilidade |
| EXECUTAR (v) | fazer um programa funcionar | fazer um procedimento (use "fazer") |
| FICAR (v) | permanecer em um estado | localizar-se (use "estar") |
| FUNDO (s) | parte mais baixa ou mais distante | dinheiro |
| LEVAR (v) | mover algo de um local para outro | demorar (use "precisar de") |
| PASSAR (v) | mover através de ou além de | aplicar (use "aplicar") |
| PODER (v) | possibilidade ou capacidade | permissão vaga |
| SEGUIR (v) | vir depois de | obedecer (use "obedecer") |
